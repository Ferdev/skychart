# Security policy

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's private vulnerability reporting for this repository. Include the affected route or component, reproduction steps, impact, and any suggested mitigation.

We will acknowledge a report as soon as practical, investigate it, and coordinate disclosure after a fix is available. This project does not currently promise a fixed response-time SLA.

## Supported version

Security fixes are applied to the current `trunk` branch and the currently deployed release. Older revisions are not maintained.
